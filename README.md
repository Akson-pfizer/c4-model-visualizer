# C4 Modelling Platform (`c4-model-visualizer`)

> *“Design is the silent ambassador of thought; code is merely its echo.”*

An interactive C4 software architecture modelling, visualization, and Confluence documentation suite powered by a **Svelte 5 + SvelteFlow frontend**, a **7-Agent FastAPI Backend**, **7 Reusable Agent Skills**, and **LM Studio local LLM inference** (with deterministic Python AST / source-tree fallback).

---

## Repository Structure

```text
c4-model-visualizer/
├── docker-compose.yml          # Orchestrates frontend (:8080) and backend (:8000) services
├── frontend/                   # Svelte 5 + Vite + @xyflow/svelte SPA (Visualizer & Developer tabs)
│   └── README.md               # Frontend architecture, Mermaid diagrams & setup guide
├── backend/                    # FastAPI multi-agent service (Manager, Supervisor, 4 Subagents, Doc Agent)
│   └── README.md               # Backend architecture, Mermaid diagrams & API reference
├── skills/                     # 7 reusable agent skills (SKILL.md definitions)
│   ├── README.md
│   ├── read-code/SKILL.md
│   ├── draw-diagram/SKILL.md
│   ├── execute-sandbox/SKILL.md
│   ├── follow-workflows/SKILL.md
│   ├── evaluate-metrics/SKILL.md
│   ├── validate-repair/SKILL.md
│   └── confluence-export/SKILL.md
└── documentation/              # Generated by c4-doc-agent (Mermaid .mmd, .svg, .png & Confluence Markdown)

    ├── DIAGRAM_REVIEW_AND_SANDBOX_REPORT.md

    └── images/

        └── png/                # 6 high-resolution .png diagram files for Confluence
```

## Quick Start

### Docker Compose (Frontend + Backend)

```bash
cd c4-model-visualizer
docker compose up --build
```

- **Frontend UI**: `http://localhost:8080`
- **Backend API**: `http://localhost:8000`

### Generate Confluence Documentation Suite (`c4-doc-agent`)

```bash
cd c4-model-visualizer/backend
./.venv/bin/python scripts/run_doc_agent.py
```
